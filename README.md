# 擬似一眼体験アプリ (DSLR Experience Sim)

このプロジェクトは、一眼レフカメラ（DSLR）の露出設定（F値、シャッタースピード、ISO）が写真にどのような影響を与えるかをブラウザ上でリアルタイムに体験できるシミュレーションアプリです。

## 🌟 主な機能

- **リアルタイム露出シミュレーション:** カメラ映像に対して、設定に基づいた明るさ、ボケ、ノイズをリアルタイムで適用します。
- **F値 (Aperture):** 
  - 小さな値（開放）にすると被写界深度が浅くなり、背景がボケます。
  - 大きな値（絞り）にすると全体にピントが合いますが、F8以上では強い光源に「光条（スターバースト）」が発生します。
- **シャッタースピード (Shutter Speed):**
  - 遅いシャッタースピードでは、露出時間が長くなり画面が明るくなります。また、残像感のある長秒露光をシミュレートします。
- **ISO感度:**
  - 高感度に設定すると暗い場所でも明るく写りますが、デジタル特有の「高感度ノイズ」が発生します。
- **露出三角形 (Exposure Triangle):** UI上で3つの要素のバランスを視覚的に確認できます。
- **写真撮影:** 現在の設定を反映した状態で写真を「撮影」し、ギャラリーのように確認できます。

## 🚀 起動方法

### 1. 依存関係のインストール
```bash
pnpm install
```

### 2. 開発サーバーの起動
```bash
pnpm dev
```
起動後、ブラウザで `http://localhost:5173` にアクセスしてください。

## 📸 使い方

1. **カメラを起動:** 画面右上の「Camera ON」ボタンを押してカメラを許可します。
2. **パラメータを選択:** 下部のダイヤル付近にある「SS」「F」「ISO」のボタン、または中央の三角形をタップして、調整したい項目を選びます。
3. **ダイヤルを回す:** 中央の大きな円形ダイヤルをスワイプ（またはドラッグ）して値を変更します。
4. **プレビューを確認:** 設定に応じて画面の明るさやボケ味が変わるのを確認します。
5. **撮影:** 右下の白いシャッターボタンを押すと、現在の設定で静止画をキャプチャします。

## 📂 ディレクトリ構造

- **src/components/**: UIコンポーネント
  - `CameraView.tsx`: メインのカメラ画面とUIレイアウト
  - `CircularDial.tsx`: 直感的な操作が可能な回転式ダイヤルUI
  - `ExposureTriangle.tsx`: 露出の3要素を可視化する三角形UI
  - `PhoneFrame.tsx`: スマホ実機のような外観を作るフレーム
- **src/hooks/**: カスタムフック
  - `useCamera.ts`: デバイスカメラの制御と設定管理
  - `useFrameProcessor.ts`: カメラの各フレームに対してエフェクト（ボケ・ノイズ・光条）を適用するメインロジック
  - `useExposure.ts`: 露出計算（EV値）のロジック
- **src/utils/**: ユーティリティ
  - `imageEffects.ts`: Canvas APIを使用した高度な画像処理（DOF、ノイズ生成など）
  - `exposureCalc.ts`: 物理的な露出計算式
  - `constants.ts`: カメラがサポートするF値やISOの定数リスト

## 🛠 技術スタック

- **Frontend:** React 19 (TypeScript)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Camera:** react-webcam + Canvas API (Frame Processing)
- **Package Manager:** pnpm
